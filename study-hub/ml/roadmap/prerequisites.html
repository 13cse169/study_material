Linear Algebra Essential
Why it matters: Vectors, matrices and tensors are the data structures of ML. Every neural network layer is a matrix multiplication.
  • ✓
    Vectors & Scalars — Operations, dot product, magnitude, unit vectors
  • ✓
    Matrices — Addition, multiplication, transpose, inverse
  • ✓
    Eigenvalues & Eigenvectors — Critical for PCA and dimensionality reduction
  • ✓
    SVD (Singular Value Decomposition) — Used in recommendations, compression
  • ✓
    Norms & Distance Metrics — L1, L2, cosine similarity
Python · NumPy Linear Algebra
import numpy as np # Matrix multiplication A = np.array([[1,2],[3,4]]) B = np.array([[5,6],[7,8]]) C = np.dot(A, B) # or A @ B # Eigenvalues eigenvalues, eigenvectors = np.linalg.eig(A) # SVD decomposition U, S, Vt = np.linalg.svd(A)

Calculus Essential
Why it matters: Gradient descent — the backbone of training — is pure calculus. You need derivatives to understand how models learn.
  • ✓
    Derivatives — Rules, chain rule, partial derivatives
  • ✓
    Gradients — Multivariable calculus, gradient vectors
  • ✓
    Integrals — Area under curve (used in probability)
  • ✓
    Optimization — Minima, maxima, saddle points
  • ✓
    Gradient Descent — SGD, mini-batch, learning rate
  • ✓
    Backpropagation — Chain rule applied to neural networks

Statistics & Probability Essential
Descriptive Statistics ▼
  • ✓
    Mean, Median, Mode — Central tendency measures
  • ✓
    Variance & Standard Deviation — Spread of data
  • ✓
    Correlation & Covariance — Relationship between variables
  • ✓
    Histograms, Box Plots, Scatter Plots
Probability Theory ▼
  • ✓
    Probability rules — addition, multiplication, conditional
  • ✓
    Bayes' Theorem — P(A|B) = P(B|A)·P(A) / P(B)
  • ✓
    Probability Distributions — Normal, Bernoulli, Binomial, Poisson
  • ✓
    Expected Value & Variance
Inferential Statistics ▼
  • ✓
    Hypothesis Testing — Null/alternative hypothesis, p-values
  • ✓
    Confidence Intervals
  • ✓
    t-test, Chi-square, ANOVA
  • ✓
    Central Limit Theorem
