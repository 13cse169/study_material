Scaling & Normalization

StandardScaler

z = (x - μ) / σ. Zero mean, unit variance. Best for normally distributed features, SVMs, neural nets.

sklearn.preprocessing

MinMaxScaler

Scales to [0,1]. Good for neural networks and image pixel values. Sensitive to outliers.

sklearn.preprocessing

RobustScaler

Uses median and IQR. Best when data has outliers that shouldn't be removed.

sklearn.preprocessing
Python · Preprocessing Pipeline
from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler, OneHotEncoder from sklearn.impute import SimpleImputer from sklearn.compose import ColumnTransformer num_pipe = Pipeline([ ('impute', SimpleImputer(strategy='median')), ('scale', StandardScaler()) ]) cat_pipe = Pipeline([ ('impute', SimpleImputer(strategy='most_frequent')), ('encode', OneHotEncoder(handle_unknown='ignore')) ]) preprocessor = ColumnTransformer([ ('num', num_pipe, num_features), ('cat', cat_pipe, cat_features) ])

Train/Validation/Test Split
  • ✓
    train_test_split — stratified splitting for imbalanced classes
  • ✓
    80/20 or 70/15/15 splits — common practice
  • ✓
    No data leakage — always fit scaler on train only!
  • ✓
    Stratified splits — preserve class distribution
⚠️ Data Leakage Warning: Never fit your preprocessor on the test set. Always fit on training data only, then transform both train and test. This is one of the most common ML mistakes.
