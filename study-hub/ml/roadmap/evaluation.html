Classification Metrics

Accuracy

Correct / Total. Misleading for imbalanced classes — avoid using alone.

Basic

Precision & Recall

Precision = TP/(TP+FP). Recall = TP/(TP+FN). Trade-off depends on use case.

Core

F1 Score

Harmonic mean of Precision & Recall. Best for imbalanced datasets.

Imbalanced

ROC-AUC

Area Under ROC Curve. Model's ability to discriminate between classes. 0.5 = random, 1.0 = perfect.

Ranking

Confusion Matrix

True/False Positives/Negatives grid. Visualizes all classification outcomes at once.

Visual

Log Loss

Penalizes confident wrong predictions. Used when probability outputs matter.

Probabilistic
📏
Regression Metrics
  • ✓
    MAE — Mean Absolute Error. Robust to outliers, easy to interpret.
  • ✓
    MSE / RMSE — Penalizes large errors more. RMSE in same units as target.
  • ✓
    R² Score — Proportion of variance explained. 1.0 = perfect, can be negative.
  • ✓
    MAPE — Mean Absolute Percentage Error. Good for business reporting.
🔄
Cross-Validation & Overfitting
Cross-Validation Strategies ▼
  • ✓
    K-Fold CV — split data into K folds, rotate train/val
  • ✓
    Stratified K-Fold — preserve class distribution in each fold
  • ✓
    Leave-One-Out (LOO) — extreme case, useful for small datasets
  • ✓
    Time Series Split — respect temporal order, no future leakage
Python · Cross Validation
from sklearn.model_selection import cross_val_score, StratifiedKFold cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42) scores = cross_val_score(model, X, y, cv=cv, scoring='f1_macro') print(f"CV F1: {scores.mean():.3f} ± {scores.std():.3f}")
Bias-Variance Tradeoff ▼
  • ✓
    High Bias = Underfitting — model too simple, poor training score
  • ✓
    High Variance = Overfitting — great training score, poor test score
  • ✓
    Learning curves — diagnose bias vs variance visually
  • ✓
    Regularization — adds penalty to reduce overfitting
🎛️
Hyperparameter Tuning
  • ✓
    GridSearchCV — exhaustive search over param grid
  • ✓
    RandomizedSearchCV — random sampling, faster for large grids
  • ✓
    Bayesian Optimization — Optuna, Hyperopt — smarter search
  • ✓
    Early stopping — stop training when validation loss plateaus
