Supervised Learning
Regression Algorithms ▼
  • ✓
    Linear Regression — Least squares, OLS, assumptions (linearity, homoscedasticity)
  • ✓
    Ridge & Lasso — L2 and L1 regularization, feature selection via Lasso
  • ✓
    Polynomial Regression — Non-linear relationships via feature transformation
  • ✓
    ElasticNet — Combines L1 + L2, best of both worlds
Classification Algorithms ▼
  • ✓
    Logistic Regression — Sigmoid function, log-odds, decision boundary
  • ✓
    Decision Trees — Gini impurity, information gain, pruning
  • ✓
    K-Nearest Neighbors (KNN) — Distance metrics, curse of dimensionality
  • ✓
    Naive Bayes — Probabilistic classifier, Gaussian/Multinomial variants

Unsupervised Learning
Clustering ▼
  • ✓
    K-Means — Centroids, inertia, elbow method, choosing K
  • ✓
    DBSCAN — Density-based, handles noise and arbitrary shapes
  • ✓
    Hierarchical Clustering — Dendrograms, linkage methods
  • ✓
    Gaussian Mixture Models — Soft cluster assignments via EM
Dimensionality Reduction ▼
  • ✓
    PCA — Principal Component Analysis, explained variance ratio
  • ✓
    t-SNE — Visualizing high-dimensional data in 2D/3D
  • ✓
    UMAP — Faster alternative to t-SNE, preserves global structure
  • ✓
    LDA — Linear Discriminant Analysis for supervised dimensionality reduction
